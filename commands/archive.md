---
description: Retire a stored memory topic to the archive
argument-hint: <file> [--scope global|project-personal|project-shared]
---

Archive this memory topic: $ARGUMENTS

Run `python3 -m muse_memory archive` from the plugin directory (or the equivalent `muse-memory` CLI) with the file reference (scope/file or file plus --scope, default project-personal), and confirm the archival in one line. Archived topics stay searchable with recall --include-archive. Do not narrate the commands while they run.
